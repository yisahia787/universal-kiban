# universal-kiban

ユニバーサル基板上での部品配置・配線をブラウザで設計できる Web アプリです。GitHub Pages で公開し、インストールせずに使えます。

作業の流れ：基板サイズを指定 → 部品をリストアップ → 部品面・はんだ面で配置と配線 → 確認・出力

- 仕様書: [docs/SPEC.md](docs/SPEC.md)

## 主な機能（現在）

- 基板サイズの指定（穴数 / mm）、プリセット、片面・両面スルーホール、使用禁止穴
- 部品棚（抵抗、コンデンサ、LED、ダイオード、TO-92、TO-220、DIP、ピンヘッダ、ピンソケット、端子台、タクトスイッチなど）から、使う部品の種類を 1 クリックで手元に置く
- 手元の部品は何個でも配置でき、ピンヘッダ・ピンソケットは端のドラッグで長さを変えられる
- 部品面とはんだ面を並べて（または重ねて）表示し、どちらの面でも配置・配線を編集
- すずめっき線・はんだブリッジ・被覆線（両面）。穴の真上を通る場合だけ導通する判定
- ネット（導通）の自動計算とハイライト、ネット名
- 配置チェック（穴の重複・基板外・使用禁止穴・外形の重なり）、未接続ピンの警告
- 自動保存（ブラウザ内）、JSON での保存・読み込み、元に戻す / やり直し、部品表 CSV

## 公開（GitHub Pages）

`main` ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）がビルドして GitHub Pages に公開します。
初回のみ、リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。
