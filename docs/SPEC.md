# ユニバーサル基板 配置・配線設計アプリ 仕様書

- 文書バージョン: 0.1（初版ドラフト）
- 作成日: 2026-11-10
- 対象リポジトリ: `universal-kiban`

---

## 1. 概要

### 1.1 目的
ユニバーサル基板（穴あき基板、2.54mm ピッチ）に電子部品を実装する前に、
**部品の配置と配線をブラウザ上で設計・確認できる** Web アプリを作成する。
紙や表計算ソフトでの手書き設計を置き換え、配線ミス・短絡・未接続を事前に発見できるようにする。

### 1.2 基本方針
- **インストール不要**：GitHub Pages で公開し、URL を開くだけで使える。
- **サーバー不要**：すべての処理はブラウザ内で完結する。データは端末内（localStorage）とファイル（JSON）に保存する。
- **シンプルな作業の流れ**：
  1. 基板のサイズを決める
  2. 使う部品をリストアップする
  3. 部品を基板上に配置する
  4. 配線をつなげる
  5. 確認して保存・出力する

### 1.3 想定ユーザー
- 電子工作の趣味者、学生、試作を行うエンジニア
- 回路図は描けるが、ユニバーサル基板への落とし込みに手間を感じている人

### 1.4 対象外（本アプリではやらないこと）
- 回路図エディタ、回路シミュレーション
- プリント基板（PCB）の製造データ（ガーバー）出力
- 自動配置・自動配線（将来検討、§12 参照）

## 2. 用語定義

| 用語 | 意味 |
|---|---|
| 穴（ホール） | 基板上の部品リードを通す穴。2.54mm 間隔の格子状に並ぶ |
| 座標 | 穴の位置。列（X）を `A, B, C…`、行（Y）を `1, 2, 3…` で表す（例: `C5`）。内部的には 0 始まりの整数 `(x, y)` |
| 部品面（表面） | 部品を載せる面 |
| はんだ面（裏面） | はんだ付けを行う面。表から見ると左右が反転する |
| ピン | 部品のリード（足）。1 つのピンは 1 つの穴を占有する |
| フットプリント | 部品のピン配置の形状（例: DIP-8、TO-92） |
| 配線（ワイヤ） | 穴と穴を電気的につなぐ線。ジャンパ線・すずめっき線・はんだブリッジなど |
| ネット | 電気的に互いにつながっている穴（ピン）の集合 |
| リファレンス（Ref） | 部品の識別名（例: `R1`, `C2`, `U1`） |

## 5. 機能仕様

### 5.1 ステップ①：基板設定

#### 5.1.1 基板サイズの指定
- 指定方法を 2 通り用意する。
  - **穴数で指定**：列数 × 行数（例: 30 × 20）
  - **外形寸法で指定**：幅 × 高さ（mm）→ 穴数を自動計算して表示
- 入力範囲：列・行ともに 2〜200 穴
- ピッチ：既定 2.54mm（将来の拡張用に設定値として保持する）
- 外形余白（基板端から最初の穴中心までの距離）：既定 1.27mm 程度、変更可

#### 5.1.2 プリセット
- 一般に流通している代表的なサイズのユニバーサル基板をプリセットとして選べる。
- プリセット値は実装時に市販品の寸法を確認したうえで定義ファイル（JSON）に記載する。
- ユーザーが現在の設定を「マイプリセット」として保存できる（localStorage）。

#### 5.1.3 基板の種類
| 種類 | MVP | 説明 |
|---|---|---|
| 穴のみ（片面・独立ランド） | ○ | 各穴が独立。最も一般的 |
| 両面スルーホール | ○ | 表裏どちらからもはんだ付け可。表示上の扱いは片面と同じ |
| ストリップボード（帯状パターン） | 将来 | 行方向の穴が最初から導通。カットポイントの指定が必要 |
| ブレッドボード型パターン | 将来 | ブレッドボードと同じ導通パターン |

#### 5.1.4 その他
- 取り付け穴（ネジ穴）の位置を指定し、その周辺の穴を「使用禁止」にできる（MVP では任意の穴を使用禁止に設定できる機能として実装）。
- 基板サイズを後から変更した場合、範囲外になる部品・配線があれば警告し、確認のうえで削除または変更を取り消す。

### 5.2 ステップ②：部品リスト

#### 5.2.1 部品ライブラリ（組み込み）
MVP で以下の部品を用意する。ピン配置は 2.54mm グリッド上の相対座標で定義する。

| 分類 | 部品 | 可変パラメータ |
|---|---|---|
| 受動部品 | 抵抗（アキシャル） | リード間隔（穴数、既定 4 ピッチ＝ 10.16mm。3〜10） |
| | セラミックコンデンサ | リード間隔（1〜4 ピッチ） |
| | 電解コンデンサ | リード間隔、極性表示、外形直径 |
| | 半固定抵抗（3 ピン） | ピン配置（直線 / 三角） |
| | インダクタ（アキシャル / ラジアル） | リード間隔 |
| 半導体 | ダイオード（アキシャル） | リード間隔、極性表示 |
| | LED（φ3 / φ5） | 極性表示 |
| | トランジスタ / レギュレータ（TO-92 / TO-220） | ピン名（E/B/C、IN/GND/OUT など） |
| | IC（DIP） | ピン数（4〜40、偶数）、列間隔（3 / 6 / 9 ピッチ = 300/600/900mil 相当の行間） |
| コネクタ等 | ピンヘッダ 1 列 / 2 列 | ピン数 |
| | 端子台 | ピン数、ピッチ（2.54 / 5.08mm） |
| | タクトスイッチ（4 ピン） | — |
| | ジャンパピン / テストピン（1 ピン） | — |

- ピンには**ピン番号**と**ピン名**（任意）を持たせる。例: DIP-8 の 1 番ピンに `VCC`。
- 部品の**外形（ボディ）**は占有範囲として描画し、部品同士のボディの重なりを警告する。

#### 5.2.2 カスタム部品
- ユーザーがグリッド上でピン位置をクリックして独自部品を作成できる。
  - 名前、リファレンス接頭辞（例: `U`, `M`）、外形矩形、各ピンの番号・名前を指定
- 作成したカスタム部品はプロジェクト内に保存し、別途「マイライブラリ」として localStorage に保存・JSON 書き出しもできる。

#### 5.2.3 部品リストの操作
- ライブラリから部品を選び、**数量**を指定して追加する。
- 追加時にリファレンスを自動採番（`R1, R2…`）。手動で変更可能（重複時は警告）。
- 各部品に**値**（例: `10kΩ`, `100nF`, `NE555`）と**メモ**を入力できる。
- リストの各行に配置状態（未配置 / 配置済み）を表示する。
- 並べ替え（Ref 順・種類順）、検索フィルタ。
- 部品を削除すると、関連する配置情報も削除する（配線は残し、未接続警告の対象とする）。
- 部品表（BOM）を CSV で書き出せる（Ref、種類、値、数量、メモ）。

### 5.3 ステップ③：部品配置

#### 5.3.1 基本操作
| 操作 | 内容 |
|---|---|
| 配置 | 部品リストからキャンバスへドラッグ＆ドロップ、またはリストで選択後に基板をクリック |
| 移動 | 配置済み部品をドラッグ（穴グリッドにスナップ） |
| 回転 | `R` キー / ボタンで 90° 回転（時計回り。`Shift+R` で反時計回り） |
| 反転 | 不要（部品は部品面に実装する前提）。※ はんだ面表示は §5.6 の表示切替で扱う |
| 削除 | `Delete` キー → 未配置に戻る（部品リストからは消えない） |
| 複数選択 | `Shift+クリック`、矩形ドラッグ選択。まとめて移動・回転 |
| 複製 | `Ctrl+D`（同種の部品を新しい Ref で追加） |
| リード間隔変更 | アキシャル部品はプロパティパネル、または端点ハンドルのドラッグで変更 |

#### 5.3.2 配置時のチェック（リアルタイム）
- **穴の重複**：別部品のピンと同じ穴 → 配置不可（赤表示）
- **基板外**：ピンが基板範囲外 → 配置不可
- **使用禁止穴**：配置不可
- **ボディの重なり**：警告（黄表示）だが配置は可能（立てて実装する場合などを考慮）

#### 5.3.3 表示
- 部品はボディ外形・ピン位置・Ref・値を描画。ピン 1 番や極性（＋/−、カソード）がわかる表示を行う。
- ピンにマウスを乗せるとピン番号・ピン名・座標をツールチップ表示。

### 5.4 ステップ④：配線

#### 5.4.1 配線の種類
| 種類 | 面 | 既定色 | 用途 |
|---|---|---|---|
| すずめっき線（裸線） | はんだ面 | 銀 | 裏面の直線的な配線 |
| はんだブリッジ | はんだ面 | 灰 | 隣接穴同士の接続（1 ピッチのみ） |
| ジャンパ線（被覆線） | 部品面 | 任意（赤・黒・青・緑・黄など） | 交差や離れた箇所の接続 |
| 被覆線（裏面） | はんだ面 | 任意 | 裏面で他の配線をまたぐ接続 |

- 配線の色はユーザーが変更可能（例: 電源は赤、GND は黒）。

#### 5.4.2 配線の描き方
- 配線ツールで**始点の穴をクリック → 途中の折れ点の穴をクリック → 終点の穴でダブルクリック（または `Enter`）** で確定。`Esc` で中断。
- 折れ点は必ず穴の位置（グリッド）に置く。
- 既定は**水平・垂直のみ**（直交配線）。`Shift` 押下中は斜め（45°・任意）を許可。
- 配線は**穴を通過するとその穴と接続する**扱いとする（すずめっき線を穴に沿わせて各穴ではんだ付けする実装を想定）。
  - 被覆線（ジャンパ）は始点・終点のみ接続し、途中の穴とは接続しない。
- 配線の始点・終点・折れ点はドラッグで後から編集できる。配線を選択して `Delete` で削除。

#### 5.4.3 ネット（導通）計算
- 「同じ穴にあるピン・配線端点」および「配線で結ばれた穴」を連結して**ネット**を自動計算する（Union-Find）。
- 穴またはピンをクリック（ネットハイライトモード）すると、同じネットに属するすべての穴・配線を強調表示する。
- ネットに名前を付けられる（例: `VCC`, `GND`）。名前付きネットは右パネルの一覧に表示。

#### 5.4.4 接続指示（任意機能・MVP 後半）
- 回路図が手元にある前提で、「ピン A とピン B をつなぐべき」という**接続指示（ネットリスト）**を入力できる。
  - 入力方法：ピンを順にクリック、またはテキスト（例: `U1.8 R1.1 C1.1 VCC`）で入力
- 接続指示がある場合、未配線の接続を**ラッツネスト（細い点線）**で表示し、配線の進捗（○/○ 接続完了）を表示する。

### 5.5 ステップ⑤：確認・出力

#### 5.5.1 チェック（DRC）
「チェック実行」ボタン、および編集中のリアルタイム表示で以下を検出する。

| No | チェック内容 | 種別 |
|---|---|---|
| C1 | 配線が 1 本もつながっていない部品ピン | 警告 |
| C2 | はんだ面の裸線同士が穴以外の場所で交差（＝短絡） | エラー |
| C3 | 1 つの穴に 3 本以上の線・リードが集中（実装困難） | 警告 |
| C4 | 異なる名前のネット同士がつながっている（例: `VCC` と `GND` が短絡） | エラー |
| C5 | 接続指示（ネットリスト）があるのに未配線の接続 | エラー |
| C6 | 接続指示にない余計な接続 | 警告 |
| C7 | 部品ボディの重なり | 警告 |
| C8 | 使用禁止穴の使用 | エラー |

- 結果は一覧表示し、項目をクリックすると該当箇所へズームする。

#### 5.5.2 保存・読み込み
- **自動保存**：編集のたびに localStorage へ保存（直近のプロジェクトを復元）。
- **プロジェクトファイル**：JSON（拡張子 `.ukb.json`）としてダウンロード／読み込み（ファイル選択・ドラッグ＆ドロップ）。
- **複数プロジェクト**：localStorage 内に名前付きで複数保存できる一覧画面。

#### 5.5.3 書き出し
| 形式 | 内容 |
|---|---|
| PNG / SVG | 部品面・はんだ面（左右反転）それぞれの画像 |
| 印刷 | 原寸（1:1）印刷用レイアウト。部品面・はんだ面を並べて出力。印刷時の拡大縮小補正値を設定可 |
| CSV | 部品表（BOM）、配線リスト（始点・終点座標、種類、色、長さ） |
| JSON | プロジェクトファイル |

- 配線リストには配線長（mm）を出力し、線材の切り出し長の目安とする。

### 5.6 表示機能（全ステップ共通）
- **ズーム**：マウスホイール／ピンチ、`+` `-` キー、「全体表示」ボタン
- **パン**：スペース＋ドラッグ、中ボタンドラッグ、2 本指ドラッグ
- **表示面切替**：
  - 部品面から見る（既定）
  - はんだ面から見る（**左右反転**して表示。実際に裏返して作業するときの見え方）
  - 透過表示（両面を重ねて表示。反対面は半透明）
- **レイヤー表示切替**：部品 / 部品面配線 / はんだ面配線 / ラベル / 座標 / ラッツネスト
- **座標ラベル**：基板の上辺・左辺に列（A, B, …, Z, AA, …）・行（1, 2, …）を表示
- **グリッド**：穴を円で描画。使用中の穴、使用禁止穴は区別して表示

### 5.7 編集共通機能
- **Undo / Redo**：`Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z`）。履歴は最低 100 ステップ
- **コピー / ペースト**：部品と配線をまとめてコピー（Ref は再採番）
- **キーボードショートカット一覧**：`?` キーで表示

### 5.8 キーボードショートカット（初期案）

| キー | 機能 |
|---|---|
| `V` | 選択ツール |
| `W` | 配線ツール（すずめっき線） |
| `J` | 配線ツール（ジャンパ線） |
| `N` | ネットハイライト |
| `R` / `Shift+R` | 回転 |
| `F` | 表示面切替（部品面 ⇔ はんだ面） |
| `Delete` / `Backspace` | 削除 |
| `Esc` | 操作の中断・選択解除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+S` | JSON として保存 |
| `0` | 全体表示 |
| `?` | ショートカット一覧 |

## 6. データモデル

プロジェクトは以下の JSON で表現する。座標は**穴のグリッド座標（0 始まりの整数）**で保持し、mm への換算は表示・出力時に行う。

```jsonc
{
  "format": "universal-kiban",
  "version": 1,
  "meta": {
    "name": "LED点滅回路",
    "createdAt": "2026-11-10T12:00:00Z",
    "updatedAt": "2026-11-10T12:30:00Z",
    "note": ""
  },
  "board": {
    "cols": 30,
    "rows": 20,
    "pitchMm": 2.54,
    "marginMm": 1.27,
    "type": "plain",                 // plain | double | stripboard(将来)
    "disabledHoles": [[0, 0], [29, 0]]
  },
  "customFootprints": [
    {
      "id": "custom-sensor-1",
      "name": "温度センサモジュール",
      "refPrefix": "M",
      "body": { "x": -1, "y": -1, "w": 6, "h": 3 },
      "pins": [
        { "num": "1", "name": "VCC", "x": 0, "y": 0 },
        { "num": "2", "name": "OUT", "x": 2, "y": 0 },
        { "num": "3", "name": "GND", "x": 4, "y": 0 }
      ]
    }
  ],
  "parts": [
    {
      "id": "p1",                      // 内部 ID（不変）
      "ref": "R1",
      "footprint": "resistor-axial",   // 組み込み ID またはカスタム ID
      "params": { "span": 4 },         // フットプリント固有パラメータ
      "value": "330Ω",
      "note": "",
      "placement": { "x": 3, "y": 5, "rot": 0 }   // 未配置なら null。rot: 0|90|180|270
    }
  ],
  "wires": [
    {
      "id": "w1",
      "kind": "bare",                  // bare | bridge | jumper | insulated-bottom
      "side": "bottom",                // top(部品面) | bottom(はんだ面)
      "color": "#c0c0c0",
      "points": [[3, 5], [3, 9], [8, 9]]   // 折れ点を含む穴座標の列
    }
  ],
  "nets": [
    { "name": "VCC", "anchor": { "part": "p1", "pin": "1" } }  // ネット名は代表ピンで紐づけ
  ],
  "connections": [
    { "net": "VCC", "pins": [["p1", "1"], ["p3", "8"]] }      // 接続指示（任意）
  ]
}
```

- `version` によりファイル形式の互換性を管理し、旧形式は読み込み時にマイグレーションする。
- ネット自体は保存せず、読み込み時に部品配置と配線から再計算する（名前のみ代表ピンで保存）。

### 6.1 組み込みフットプリント定義
- `src/library/footprints/*.json`（またはTS定数）として定義。パラメータからピン座標を生成する関数を持つ。
- 例: `dip` は `{ pins: 8, rowSpan: 3 }` から 8 ピンの座標を生成する。

## 7. 描画・内部処理の方針

- 描画は **SVG** を基本とする（拡大縮小に強く、SVG 書き出しや印刷と相性が良い）。
  - 200 × 200 穴（4 万穴）でも操作が重くならないよう、穴グリッドはパターン（`<pattern>`）または Canvas レイヤーで描画し、部品・配線のみを個別要素とする。
- 座標系：内部はグリッド整数座標。描画時に `px = (index * pitch + margin) * scale` で変換。
- はんだ面表示は X 座標を `cols - 1 - x` に反転して描画する（データは変更しない）。
- ネット計算は穴を頂点とする Union-Find で行い、編集のたびに再計算（数千要素で 10ms 以内を目標）。
- 状態管理は単一のプロジェクト状態オブジェクト＋コマンド（操作）単位の Undo 履歴とする。

## 8. 非機能要件

| 項目 | 要件 |
|---|---|
| 性能 | 100 × 100 穴・部品 100 個・配線 500 本で、ドラッグ操作が体感的に遅延しない（60fps 目標） |
| 起動 | 初回表示 3 秒以内（一般的な回線） |
| オフライン | Service Worker でアセットをキャッシュし、オフラインで起動・編集可能（PWA） |
| データ保護 | データは外部送信しない。localStorage 容量超過時はエラーを表示し JSON 保存を促す |
| 互換性 | プロジェクトファイルは後方互換を維持（旧バージョンのファイルを読み込める） |
| アクセシビリティ | 主要操作はキーボードでも可能。色だけに頼らない表示（線種・ラベル併用） |
| 品質 | ネット計算・DRC・フットプリント生成・ファイル入出力に単体テストを用意 |

## 9. 技術構成

| 項目 | 採用案 | 理由 |
|---|---|---|
| 言語 | TypeScript | データモデルが複雑なため型で保護する |
| ビルド | Vite | 設定が少なく、静的ファイルとして出力できる |
| UI | 軽量フレームワーク（Preact または素の TS ＋ SVG） | 依存を小さく保ち、GitHub Pages の読み込みを軽くする |
| テスト | Vitest | Vite と統合しやすい |
| 公開 | GitHub Actions で `main` へのプッシュ時にビルド → GitHub Pages へデプロイ | 手作業なしで常に最新版を公開 |

## 11. 未決事項・確認したい点

1. **ターゲット端末**：PC 前提でよいか。タブレットでの編集をどこまでサポートするか。
2. **プリセット基板**：よく使う基板の型番・サイズ（ユーザーが主に使う製品）を確認したい。
3. **はんだ面配線の表現**：すずめっき線が「通過した穴すべてと接続」の扱いでよいか（穴をまたいで浮かせる配線は被覆線として扱う）。
4. **接続指示（ネットリスト）の入力**：KiCad などの回路図ツールからのネットリスト読み込みが必要か。
5. **UI フレームワーク**：Preact か素の TypeScript か（M0 で決定）。
