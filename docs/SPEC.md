## 1. 概要

### 1.1 目的
ユニバーサル基板（穴あき基板、2.54mm ピッチ）に電子部品を実装する前に、
**部品の配置と配線をブラウザ上で設計・確認できる** Web アプリを作成する。
紙や表計算ソフトでの手書き設計を置き換え、配線ミス・短絡・未接続を事前に発見できるようにする。

### 1.2 基本方針
- **インストール不要**：GitHub Pages で公開し、URL を開くだけで使える。
- **サーバー不要**：すべての処理はブラウザ内で完結する。データは端末内（localStorage）とファイル（JSON）に保存する。
- **表裏を同時に扱う**：部品面とはんだ面を同時に表示し、どちらの面でも部品の配置と配線ができる。
- **シンプルな作業の流れ**：
  1. 基板のサイズを決める
  2. 使う部品をリストアップする
  3. 部品の配置と配線を行う（同じ画面で行う）
  4. 確認して保存・出力する

### 1.3 想定ユーザー
- 電子工作の趣味者、学生、試作を行うエンジニア
- 回路図は描けるが、ユニバーサル基板への落とし込みに手間を感じている人

### 1.4 対象外（本アプリではやらないこと）
- 回路図エディタ、回路シミュレーション
- KiCad などの外部 CAD ツールとの連携（ネットリストの読み込み・書き出しを含む）
- プリント基板（PCB）の製造データ（ガーバー）の出力
- 自動配置・自動配線
- 表面実装部品（SMD）。MVP では挿入実装部品（THT）だけを扱う

## 2. 用語定義

| 用語 | 意味 |
|---|---|
| 穴（ホール） | 基板上の部品リードを通す穴。2.54mm 間隔の格子状に並ぶ |
| ランド | 穴の周りの銅箔。はんだ付けする部分 |
| 座標 | 穴の位置。列（X）を `A, B, C…`、行（Y）を `1, 2, 3…` で表す（例: `C5`）。内部的には 0 始まりの整数 `(x, y)` で持つ。**座標は部品面から見た位置で統一する** |
| 部品面（表面, top） | 部品を載せる主な面 |
| はんだ面（裏面, bottom） | 主にはんだ付けを行う面。表から見ると左右が反転する |
| 面（side） | 部品や配線が置かれる面。`top`（部品面）または `bottom`（はんだ面） |
| ピン | 部品のリード（足）。1 つのピンは 1 つの穴に入る |
| フットプリント | 部品のピン配置の形状（例: DIP-8、TO-92） |
| 配線材 | 穴と穴をつなぐもの。すずめっき線・はんだブリッジ・被覆線の 3 種類 |
| ネット | 電気的に互いにつながっている穴の集まり |
| リファレンス（Ref） | 部品の識別名（例: `R1`, `C2`, `U1`） |

## 4. 画面構成

### 4.1 画面一覧
| 画面（ステップ） | 内容 |
|---|---|
| ① 基板設定 | 基板のサイズ・種類・使用禁止穴を設定する |
| ② 部品リスト | 部品棚から使いそうな部品の種類を手元に置く。配置済みの部品の値や Ref を編集する |
| ③ 設計（配置・配線） | 部品の配置と配線を**同じ画面で**行う。メインの作業画面 |
| ④ 確認・出力 | チェック結果の一覧、保存・書き出し |

- 画面上部のタブで自由に行き来できる。③の画面からも部品リストへの追加・編集ができる（左パネル）。

### 4.2 設計画面のレイアウト（PC）

```
┌────────────────────────────────────────────────────────────────────────┐
│ ヘッダー：プロジェクト名 | 新規 開く 保存 書き出し | Undo Redo          │
├────────────────────────────────────────────────────────────────────────┤
│ タブ：①基板  ②部品リスト  ③設計  ④確認・出力                          │
├────────────────────────────────────────────────────────────────────────┤
│ ツールバー：選択 | すずめっき線 | はんだブリッジ | 被覆線 | ネット表示 |  │
│             表示レイアウト（左右 / 上下 / 重ね） | レイヤー表示切替      │
├──────────────┬──────────────────────────┬──────────────────────────┬────┤
│ 左パネル      │ 部品面ビュー（top）       │ はんだ面ビュー（bottom）   │右  │
│ ・手元の部品  │ 部品面から見た状態        │ はんだ面から見た状態       │パネ│
│  （イメージ） │                          │ （左右反転して表示）       │ル  │
│ ・配置済みの  │ この面の部品・配線を編集  │ この面の部品・配線を編集   │    │
│   部品一覧    │                          │                          │    │
├──────────────┴──────────────────────────┴──────────────────────────┴────┤
│ ステータスバー：カーソル座標 | 操作中の面 | ツール | 警告件数 | ズーム率   │
└────────────────────────────────────────────────────────────────────────┘
```

右パネル：選択中の部品・配線のプロパティ、ネット一覧、警告一覧。

### 4.3 表裏の同時表示・同時編集
- **2 つのビュー**（部品面ビューとはんだ面ビュー）を並べて表示する。
  - はんだ面ビューは、基板を裏返して見たときと同じになるよう**左右反転**して表示する。
  - 2 つのビューのズームとスクロールは**連動**する（反転も考慮して、同じ穴が同じ高さに見える）。
  - 一方のビューで穴にカーソルを乗せると、もう一方のビューの**同じ穴**にも目印を表示する。
- **どちらのビューでも編集できる**。操作したビューの面が「操作中の面」になる。
  - 部品面ビューで置いた部品・配線は `top`、はんだ面ビューで置いたものは `bottom` になる。
- 各ビューでは、その面の部品・配線を通常表示し、**反対面のものは半透明で表示**する（重なりや位置関係を確認するため）。反対面の半透明表示はオン・オフできる。
- 表示レイアウトは次から選べる。
  - **左右並べ**（既定）
  - **上下並べ**（横長の基板向け）
  - **重ね表示**：1 つのビューに両面を重ねて表示。`Tab` キーまたはボタンで操作中の面を切り替える。操作中でない面は半透明になる。画面が狭いときに使う

## 5. 機能仕様

### 5.1 ① 基板設定

#### 5.1.1 基板サイズの指定
- 指定方法を 2 通り用意する。
  - **穴数で指定**：列数 × 行数（例: 30 × 20）
  - **外形寸法で指定**：幅 × 高さ（mm）→ 穴数を自動計算して表示
- 入力範囲：列・行ともに 2〜200 穴
- ピッチ：既定 2.54mm（設定値として保持する）
- 外形余白（基板の端から最初の穴の中心までの距離）：変更可

#### 5.1.2 プリセット
| プリセット | 入手先 | 寸法・穴数など |
|---|---|---|
| 秋月電子 P-03229（片面ガラスコンポジット Cタイプ） | https://akizukidenshi.com/catalog/g/g103229/ | 72 × 47mm、片面、CEM-3、ピッチ 2.54mm、穴径 1mm、取付穴 φ3.2mm（間隔 66 × 41mm＝各辺から 3mm）、厚さ 1.6mm。穴数は外形からの推定で 28 × 18 穴（**要確認**）。取付穴に重なる穴は使用禁止にする |

- プリセットは定義ファイル（JSON）で管理し、後から追加できる。
- ユーザーが現在の設定を「マイプリセット」として保存できる（localStorage）。

#### 5.1.3 基板の種類
| 種類 | MVP | 説明 |
|---|---|---|
| 片面（ランドは裏面のみ） | ○ | 部品面に銅箔がない。導通の扱いは §5.4.3 を参照 |
| 両面スルーホール | ○ | 表裏どちらにもランドがあり、穴の内側でつながっている |
| ストリップボード（帯状パターン） | 将来 | 行方向の穴が最初から導通している |
| ブレッドボード型パターン | 将来 | ブレッドボードと同じ導通パターン |

#### 5.1.4 その他
- 任意の穴を「使用禁止」に設定できる（ネジ穴の周りなど）。
- 基板サイズを後から変更した結果、範囲外になる部品・配線があれば警告する。ユーザーが確認したうえで、それらを削除するか変更を取り消すかを選ぶ。

### 5.2 ② 部品リスト

#### 5.2.1 部品ライブラリ（組み込み）
MVP で以下の部品を用意する。ピンの位置は 2.54mm グリッド上の相対座標で定義する。

| 分類 | 部品 | 可変パラメータ |
|---|---|---|
| 受動部品 | 抵抗（アキシャル） | リード間隔（穴数、既定 4 ピッチ。3〜10） |
| | セラミックコンデンサ | リード間隔（1〜4 ピッチ） |
| | 電解コンデンサ | リード間隔、極性表示、外形直径 |
| | 半固定抵抗（3 ピン） | ピン配置（直線 / 三角） |
| | インダクタ（アキシャル / ラジアル） | リード間隔 |
| 半導体 | ダイオード（アキシャル） | リード間隔、極性表示 |
| | LED（φ3 / φ5） | 極性表示 |
| | トランジスタ / レギュレータ（TO-92 / TO-220） | ピン名（E/B/C、IN/GND/OUT など） |
| | IC（DIP） | ピン数（4〜40、偶数）、列の間隔（3 / 6 / 9 ピッチ） |
| コネクタ等 | ピンヘッダ 1 列 / 2 列 | ピン数（端のドラッグでも変更可） |
| | ピンソケット 1 列 / 2 列 | ピン数（端のドラッグでも変更可） |
| | 端子台 | ピン数、ピッチ（2.54 / 5.08mm） |
| | タクトスイッチ（4 ピン） | — |
| | XH コネクタ（JST B*B-XH-A トップ型） | 極数（2〜16）。外形は実寸（幅 (n−1)×2.5+4.9mm、奥行 5.75mm、ピン中心から 2.35mm / 3.4mm）で描き、干渉がわかるようにする。ピッチは 2.5mm だが、2.54mm の穴に合わせて置く |
| | テストピン（1 ピン） | — |
| マイコンボード用 | ESP32-DevKitC 用ピンソケット（19 ピン × 2 列） | なし。Espressif ESP32-DevKitC V4（ESP32-WROOM-32E、秋月 販売コード 115673）の J2・J3 のピン名つき。列の間隔 25.4mm（10 ピッチ）。2 列は 1 つの部品なので一緒に動く。ボードの外形（約 54.4 × 27.9mm、前後位置は目安）を点線で表示し、外形の重なりを警告する |

- ピンには**ピン番号**と**ピン名**（任意）を持たせる。例: DIP-8 の 1 番ピンに `VCC`。
- 部品の**外形（ボディ）**は占有範囲として描画し、同じ面にある部品同士のボディの重なりを警告する。

#### 5.2.2 カスタム部品
- ユーザーがグリッド上でピンの位置をクリックして独自の部品を作れる。
  - 名前、リファレンスの接頭辞（例: `U`, `M`）、外形の矩形、各ピンの番号・名前を指定する
- 作ったカスタム部品はプロジェクト内に保存する。また「マイライブラリ」として localStorage への保存と JSON での書き出しもできる。

#### 5.2.3 部品棚と手元
部品リストは「**部品棚**」と「**手元**」の 2 つの欄で構成する。使いそうな部品の**種類だけ**を手元に置いておく機能で、個数は扱わない。

```
┌ 部品棚 ───────────[カテゴリ ▼]┐ ┌ 手元（3 種類）──────────┐
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐ │ │ ┌────┐ ┌────┐ ┌────┐ │
│ │ 図 │ │ 図 │ │ 図 │ │ 図 │ │ │ │ 図 │ │ 図 │ │ 図 │ │
│ │名前│ │名前│ │名前│ │名前│ │ │ │名前│ │名前│ │名前│ │
│ └────┘ └────┘ └────┘ └────┘ │ │ └────┘ └────┘ └────┘ │
└──────────────────────────────┘ └────────────────────────┘
```

- 部品棚：カテゴリをプルダウン（受動部品 / 半導体 / コネクタ等 / すべて）で選ぶと、その下に部品がイメージ（部品面から見た外形とピン）付きで並ぶ。
- **1 クリックで棚と手元を行き来**する。棚の部品をクリックすると手元へ、手元の部品をクリックすると棚へ戻る。手元にある部品は棚には表示しない。
- 手元の部品には、配置済みの数をバッジで表示する。手元から棚に戻しても、配置済みの部品は消えない。
- 手元の部品は、設計画面の左パネルにも同じイメージで並ぶ（§5.3.2）。

#### 5.2.4 配置済み部品の一覧
- 配置した部品（R1, R2…）を一覧表示する。
- リファレンスは配置時に自動で採番する（`R1, R2…`）。手動で変更でき、重複したときは警告する。
- 各部品に**値**（例: `10kΩ`, `100nF`, `NE555`）と**メモ**を入力できる。
- 並べ替え（Ref 順・種類順）、検索フィルタ。
- 部品を削除すると基板から取り除く。配線は残し、未接続警告の対象にする。
- 部品表（BOM）を CSV で書き出せる（Ref、種類、仕様、値、数量、メモ。同じ種類・仕様・値はまとめる）。

### 5.3 ③ 設計：部品の配置

#### 5.3.1 配置する面
- 部品は**部品面・はんだ面のどちらにも配置できる**。
- 手元の部品を**どちらのビューに置いたか**で面が決まる。配置後もプロパティパネルや `F` キーで反対面へ移せる（位置は保ったまま、反対面に裏返す）。
- はんだ面に置いた部品は、部品面ビューでは半透明かつ左右反転した外形で表示される（裏から透けて見えるイメージ）。

#### 5.3.2 基本操作
| 操作 | 内容 |
|---|---|
| 配置 | 左パネルの手元の部品をクリックしてからビューの穴をクリック（**続けて何個でも置ける**。`Esc` または基板の外をクリックで終了）、またはビューへドラッグ＆ドロップ。置くたびに新しい部品（新しい Ref）が作られる |
| 移動 | 配置済みの部品をドラッグ（穴のグリッドに吸着する） |
| 回転 | `R` キー / ボタンで 90° 回転（時計回り。`Shift+R` で反時計回り） |
| 面の入れ替え | `F` キー：選択した部品を反対面へ移す |
| 削除 | `Delete` キー：選択した部品を基板から取り除く |
| 複数選択 | `Shift+クリック`、矩形ドラッグで選択。まとめて移動・回転できる |
| 複製 | `Ctrl+D`（同じ種類の部品を新しい Ref で追加） |
| リード間隔の変更 | プロパティパネルで変更 |
| 長さの変更 | ピンヘッダ・ピンソケットを選択すると両端にハンドルが出る。ドラッグしてピン数を変える（反対側の端は動かない）。1〜40 ピン。穴の重複などで置けない長さにはできない |

#### 5.3.3 配置時のチェック（その場で表示）
- **穴の重複**：別の部品のピンと同じ穴には置けない（赤で表示）。部品面とはんだ面の部品でも同じ穴は共用できない（リードが穴を貫通するため）
- **基板外**：ピンが基板の範囲外になる位置には置けない
- **使用禁止穴**：置けない
- **ボディの重なり**：同じ面の部品同士のボディが重なると警告（黄）を出すが、置くことはできる（部品を立てて実装する場合などを考慮）

#### 5.3.4 表示
- 部品はボディ外形・ピン位置・Ref・値を描画する。1 番ピンや極性（＋/−、カソード）がわかるようにする。
- 穴にカーソルを乗せると、その穴に入っているピンの部品・ピン番号・ピン名をツールチップで表示する。**反対面に置いた部品のピンも表示する**（「（反対面）」と付ける）。
- **ピンの位置を左クリックすると、ピン名の編集欄が開く**（選択ツールのとき。反対面の部品のピンも可）。Enter で確定、Esc で取りやめ。プロパティパネルのピン一覧でも変更できる。変更したピン名は部品ごとに保存する。
- ESP32 用ソケットなど、ピン名を常に表示する部品は、ピンの横にピン名を描く。
- 抵抗は、値（例: `10k`, `4.7k`, `4k7`, `330`, `1M`）から**カラーコード**の帯を描く。有効数字 2 桁なら 4 本帯（許容差 金）、3 桁なら 5 本帯（許容差 茶）。値を変えると色も変わる。プロパティパネルに色の名前も表示する。

### 5.4 ③ 設計：配線

配線は配置と同じ画面で行う。ツールバーかショートカットでツールを切り替えるだけで、配置と配線を交互に行える。

#### 5.4.1 配線材の種類
3 種類の配線材は**部品面・はんだ面のどちらにも使える**。どちらの面になるかは、配線を描いたビューで決まる。

| 種類 | 既定色 | 説明 |
|---|---|---|
| すずめっき線（裸線） | 銀 | 被覆のない線。直上を通る穴と導通する（§5.4.3） |
| はんだブリッジ | 灰 | 隣り合う穴同士をはんだでつなぐ。上下左右に 1 ピッチのみ |
| 被覆線 | 任意（赤・黒・青・緑・黄など） | 被覆のある線。両端の穴とだけ導通する |

- 配線の色はユーザーが変更できる（例: 電源は赤、GND は黒）。

#### 5.4.2 配線の描き方
- 配線ツールで、**始点の穴をクリック → 終点の穴をクリック**すると、1 本の直線の配線ができる。`Esc` または**基板の外をクリック**で中断する。
- 終点を決めた後、終点から続けて引くことはしない。**次にクリックした穴が新しい配線の始点**になる。曲がった経路は複数の配線をつないで作る。
- 始点・終点は必ず穴の位置に置く。
- **斜めの配線も引ける**（既定は自由な方向）。`Shift` を押している間は水平・垂直にそろえる。
- はんだブリッジツールは、隣り合う 2 つの穴をクリック（またはドラッグ）して作る。
- 配線の始点・終点・折れ点は、あとからドラッグで編集できる。配線を選んで `Delete` で削除する。

#### 5.4.3 導通のルール
配線材と穴がつながっているかどうかは、次のルールで決める。

| 配線材 | 導通する穴 |
|---|---|
| すずめっき線 | 始点・終点・折れ点の穴、および**線が中心の真上を通る穴**。線が穴の真上を通らない場合（斜めの線が穴と穴の間を通る場合など）は導通しない |
| はんだブリッジ | 両端の 2 つの穴 |
| 被覆線 | 始点・終点の穴のみ（途中の穴の真上を通っても導通しない） |

- 「真上を通る」の判定：穴の中心が線分の上にちょうど乗っているとき（整数座標での共線判定）。
  - 水平・垂直の線：通過するすべての穴と導通する。
  - 斜めの線：穴の中心をちょうど通る位置だけ導通する（例: 45° の線は 1 ピッチごとの穴の中心を通るため導通する。2:1 の傾きの線は途中で穴の中心を通らないことが多く、その場合は導通しない）。
  - 斜めの線が穴の中心の近くを通るものの、真上ではない場合は、**ランドに触れるおそれ**として警告する（§5.5.1 C9）。
- **穴そのものは表裏で 1 つの導通点**とする。部品面の配線もはんだ面の配線も、同じ穴に導通していればつながる（リードや線は穴を貫通してはんだ付けされるため）。
- 片面基板（部品面にランドがない）の部品面については、次のとおり扱う。
  - すずめっき線は、始点・終点・折れ点の穴だけが導通する（線を穴に差し込んで裏ではんだ付けする前提）。途中の穴は真上を通っても導通しない。
  - はんだブリッジは使えない（部品面にランドがないため）。

#### 5.4.4 ネット（導通）の計算と表示
- 上記のルールで導通する穴と部品のピンを連結して、**ネット**を自動で計算する（Union-Find）。
- ネット表示ツールで穴またはピンをクリックすると、同じネットに属するすべての穴・配線を両方のビューで強調表示する。
- ネットに名前を付けられる（例: `VCC`, `GND`）。名前付きのネットは右パネルの一覧に表示する。

#### 5.4.5 接続指示（MVP 後半）
- 回路図をもとに「ピン A とピン B をつなぐべき」という**接続指示**をアプリ内で入力できる（外部ファイルの読み込みは行わない）。
  - 入力方法：ピンを順にクリックする、またはテキストで入力する（例: `VCC: U1.8 R1.1 C1.1`）
- 接続指示がある場合、まだ配線していない接続を**ラッツネスト（細い点線）**で表示し、配線の進み具合（○/○ 接続完了）を表示する。

### 5.5 ④ 確認・出力

#### 5.5.1 チェック
「チェック実行」ボタンで実行する。編集中もその場で警告を表示する。

| No | チェック内容 | 種別 |
|---|---|---|
| C1 | 配線が 1 本もつながっていない部品ピン | 警告 |
| C2 | 同じ面のすずめっき線同士（またはすずめっき線とはんだブリッジ）が、穴ではない場所で交差している（短絡） | エラー |
| C3 | 1 つの穴に、リード・線の端が合わせて 3 本以上集中している（実装が難しい） | 警告 |
| C4 | 名前の違うネット同士がつながっている（例: `VCC` と `GND` の短絡） | エラー |
| C5 | 接続指示があるのに、まだ配線していない接続 | エラー |
| C6 | 接続指示にない余分な接続 | 警告 |
| C7 | 同じ面での部品ボディの重なり | 警告 |
| C8 | 使用禁止穴の使用 | エラー |
| C9 | すずめっき線が斜めに穴の近くを通っているが真上ではない（ランドに触れるおそれ） | 警告 |
| C10 | 部品のボディの下を、同じ面のすずめっき線が通っている（部品のリードや金属部に触れるおそれ） | 警告 |

- 結果は一覧で表示し、項目をクリックすると該当箇所へズームする。

#### 5.5.2 保存・読み込み
- **自動保存**：編集のたびに localStorage へ保存し、次回開いたときに直前のプロジェクトを復元する。
- **プロジェクトファイル**：JSON（拡張子 `.ukb.json`）としてダウンロード・読み込み（ファイル選択・ドラッグ＆ドロップ）。
- **複数プロジェクト**：localStorage 内に名前を付けて複数保存し、一覧から開ける。

#### 5.5.3 書き出し
| 形式 | 内容 |
|---|---|
| PNG / SVG | 部品面・はんだ面（左右反転）それぞれの画像、または 2 面を並べた画像 |
| 印刷 | 原寸（1:1）の印刷用レイアウト。部品面・はんだ面を並べて出力する。プリンタの拡大縮小を補正する値を設定できる |
| CSV | 部品表（BOM）、配線リスト（面、種類、始点・終点の座標、色、長さ） |
| JSON | プロジェクトファイル |

- 配線リストには配線の長さ（mm）を出力し、線材を切り出す長さの目安にする。

### 5.6 表示機能（共通）
- **ズーム**：マウスホイール、`+` `-` キー、「全体表示」ボタン
- **スクロール**：スペース＋ドラッグ、ホイールボタンでのドラッグ
- **2 ビューの連動**：ズーム・スクロールは 2 つのビューで連動する（§4.3）
- **レイヤー表示切替**：部品面の部品 / 部品面の配線 / はんだ面の部品 / はんだ面の配線 / 反対面の半透明表示 / ラベル / 座標 / ラッツネスト
- **座標ラベル**：基板の上辺・左辺に列（A, B, …, Z, AA, …）と行（1, 2, …）を表示する。はんだ面ビューでは列の並びも左右反転する
- **穴の表示**：穴を円で描画する。使用中の穴・使用禁止の穴は見た目で区別する

### 5.7 編集の共通機能
- **Undo / Redo**：`Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z`）。履歴は少なくとも 100 操作分
- **コピー / ペースト**：部品と配線をまとめてコピーする（Ref は振り直す）。面は貼り付け先のビューに従う
- **キーボードショートカット一覧**：`?` キーで表示

### 5.8 表示専用モード（タブレット・スマートフォン）
- 画面幅が狭い、またはタッチ操作が主の端末では、**表示専用モード**で起動する。
- できること：
  - プロジェクトを開く（localStorage に保存したもの、JSON ファイル）
  - 部品面 / はんだ面の切り替え、重ね表示
  - ピンチでズーム、2 本指ドラッグでスクロール
  - 部品・穴をタップして情報（Ref、値、ピン名、座標、ネット名）を表示
  - ネットのハイライト表示
  - 部品表・チェック結果の閲覧
- 編集用の UI（ツールバー、ドラッグでの配置など）は表示しない。
- PC でも、表示専用モードに手動で切り替えられる（はんだ付け作業中に横に置いて見る用途）。

## 6. データモデル

プロジェクトは以下の JSON で表現する。座標は**部品面から見た穴のグリッド座標（0 始まりの整数）**で持ち、mm への換算と、はんだ面での左右反転は表示・出力のときに行う。

```jsonc
{
  "format": "universal-kiban",
  "version": 1,
  "meta": {
    "name": "LED点滅回路",
    "createdAt": "2026-11-10T12:00:00Z",
    "updatedAt": "2026-11-10T12:30:00Z",
    "note": ""
  },
  "hand": ["resistor-axial", "led", "pin-header"],   // 手元に置いた部品の種類（個数は持たない）
  "board": {
    "preset": "akizuki-p03229",      // プリセットを使った場合のみ
    "cols": 30,
    "rows": 20,
    "pitchMm": 2.54,
    "marginMm": 1.27,
    "type": "single",                // single(片面) | double(両面スルーホール)
    "disabledHoles": [[0, 0], [29, 0]]
  },
  "customFootprints": [
    {
      "id": "custom-sensor-1",
      "name": "温度センサモジュール",
      "refPrefix": "M",
      "body": { "x": -1, "y": -1, "w": 6, "h": 3 },
      "pins": [
        { "num": "1", "name": "VCC", "x": 0, "y": 0 },
        { "num": "2", "name": "OUT", "x": 2, "y": 0 },
        { "num": "3", "name": "GND", "x": 4, "y": 0 }
      ]
    }
  ],
  "parts": [
    {
      "id": "p1",                      // 内部 ID（変わらない）
      "ref": "R1",
      "footprint": "resistor-axial",   // 組み込みの ID またはカスタムの ID
      "params": { "span": 4 },         // フットプリントごとのパラメータ
      "value": "330Ω",
      "note": "",
      "placement": {                   // 部品は配置した時点で作られる
        "side": "top",                 // top | bottom
        "x": 3, "y": 5,
        "rot": 0                       // 0 | 90 | 180 | 270（その面から見た回転）
      }
    }
  ],
  "wires": [
    {
      "id": "w1",
      "kind": "bare",                  // bare(すずめっき線) | bridge(はんだブリッジ) | insulated(被覆線)
      "side": "bottom",                // top | bottom
      "color": "#c0c0c0",
      "points": [[3, 5], [3, 9], [8, 9]]   // 始点・折れ点・終点の穴座標
    }
  ],
  "nets": [
    { "name": "VCC", "anchor": [3, 5] }    // ネット名は代表の穴で紐づける
  ],
  "connections": [
    { "net": "VCC", "pins": [["p1", "1"], ["p3", "8"]] }   // 接続指示（任意）
  ]
}
```

- `version` でファイル形式の互換性を管理し、古い形式は読み込み時に変換する。
- ネットの中身は保存せず、読み込み時に部品配置と配線から計算し直す（名前だけを代表の穴で保存する）。
- はんだ面の部品のピン座標は「部品面から見た座標」に変換して計算する（はんだ面から見て右にあるピンは、部品面から見ると左にある）。

### 6.1 組み込みフットプリントの定義
- `src/library/footprints/` に定義する。パラメータからピン座標を作る関数を持つ。
- 例: `dip` は `{ pins: 8, rowSpan: 3 }` から 8 本のピンの座標を作る。

## 7. 描画・内部処理の方針

- 描画は **SVG** を基本とする（拡大縮小に強く、SVG 書き出しや印刷と相性が良い）。
  - 200 × 200 穴（4 万穴）でも操作が重くならないように、穴のグリッドはパターン（`<pattern>`）または Canvas で描画し、部品・配線だけを個別の要素にする。
- 2 つのビューは同じプロジェクト状態を描画する。はんだ面ビューは X 座標を `cols - 1 - x` に反転して描画する（データは変更しない）。
- 導通の判定：配線の各線分について、線分の上にある格子点を整数演算で列挙する（線分の差分ベクトル `(dx, dy)` を `gcd(|dx|, |dy|)` で割った刻みで進む）。
- ネットの計算は、穴を頂点とする Union-Find で行い、編集のたびに計算し直す（数千要素で 10ms 以内を目標）。
- 状態管理は、1 つのプロジェクト状態オブジェクトと、操作（コマンド）単位の Undo 履歴で行う。

## 8. 非機能要件

| 項目 | 要件 |
|---|---|
| 性能 | 100 × 100 穴・部品 100 個・配線 500 本で、2 ビュー同時表示でもドラッグ操作が遅れない（60fps 目標） |
| 起動 | 初回表示 3 秒以内（一般的な回線） |
| オフライン | Service Worker でアセットをキャッシュし、オフラインで起動・編集できる（PWA） |
| データ保護 | データは外部に送信しない。localStorage の容量を超えたときはエラーを表示し、JSON での保存を促す |
| 互換性 | プロジェクトファイルの後方互換を保つ（古いバージョンのファイルを読み込める） |
| アクセシビリティ | 主な操作はキーボードでもできる。色だけに頼らない表示（線種・ラベルを併用） |
| 品質 | 導通判定・ネット計算・チェック・フットプリント生成・ファイル入出力に単体テストを用意する |
